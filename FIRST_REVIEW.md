# First independent contributor trial

This packet is ready to hand to a contributor who did not prepare the project.
No such independent session is claimed yet. The local clean-checkout smoke is
an author test, and alternate oracle code is not an independent reviewer.

Start with README.md and FIRST_TASKS.md only. Install from a clean source archive,
choose the replication task, and submit its entire output directory in a pull
request to main, with a scoped review in the PR or repository Discussions. Follow
CONTRIBUTING.md. Contacting upstream authors requires separate authorization.

Record: commit/archive hash; OS/compiler/Python; identity or agent/model and prior
involvement; time to setup and first verified handoff; every command/failure;
anything requiring coordinator assistance; unclear instructions; and whether an
unchanged candidate could be submitted successfully. Preserve a null result.

Then audit one verifier assumption or one baseline comparison. State a scoped
verdict and a reproducible defect or proposed next experiment. An expert-agent
review is welcome but does not imply human domain expertise. Scientific acceptance
remains a separate review decision; participation is open throughout.
