# Review request and contribution handoff

Participation is open. Review the exact local commit and source/instance hashes.
Run the candidate checker, negative controls and a deterministic repair replay.
State your expertise, model/agent provenance, prior involvement and reviewed scope.
Do not count the author-prepared trial as independent or human expert review.

Questions: Are cost and collision semantics correct? Are local starting witnesses
competitive enough? Does the sampling or budget favor one policy? Which useful
workload and modern baselines should follow? Is a new route gain, a useful software
change, a transferable heuristic or a novel algorithm actually established?

A handoff should include the task, inherited certificate hash, method/source hashes,
all seeds and attempts, budgets and actual runtime, input provenance, failure modes,
verified output path, all three metrics, interpretation and unresolved issues.
Submit a scoped decision with reproduction commands; scientific acceptance and
public promotion are separate from open local contributions.
